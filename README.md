- Hybrid search combining vector similarity and full-text search
- Reciprocal Rank Fusion for result ranking
- Tenant-scoped document access and evaluation tooling

### 02 — DispatchAI

**AI orchestration and controlled execution**

An early-stage engine designed to connect LLM-powered workflows with application integrations while keeping business logic under the host system's control.

- Cryptographically signed integration requests
- Integration-scoped idempotency
- Explicit orchestration and execution lifecycle
- Separation of model output from authoritative business data

`Go` `API Security` `Idempotency` `AI Orchestration`
