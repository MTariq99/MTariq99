## 🚀 Featured Projects

### 1. Retrievion — Multi-Tenant RAG Application

A Go-based retrieval-augmented generation application focused on document retrieval, tenant isolation, and grounded LLM responses.

**Key engineering areas**
- Go backend architecture and API development.
- PostgreSQL and pgvector for vector similarity search.
- Hybrid retrieval using vector search and PostgreSQL full-text search.
- Reciprocal Rank Fusion (RRF) for combining retrieval results.
- Document ingestion, chunking, and embedding workflows.
- Evaluation tooling for measuring retrieval and answer quality.

**Tech stack:** Go · PostgreSQL · pgvector · Redis · RabbitMQ · Gemini

[View Retrievion on GitHub](https://github.com/MTariq99/retrievion)

### 2. DispatchAI — AI Orchestration Engine

An early-stage project exploring a reusable AI orchestration and dispatch layer for applications that need controlled LLM execution and integration with host-system business logic.

**Key engineering areas**
- Request authentication using cryptographic signatures.
- Idempotency and reliable request handling.
- AI orchestration and execution lifecycle design.
- Integration boundaries between the orchestration engine and host applications.
- Separation of LLM-generated output from authoritative business data and permissions.

**Core principle:** LLMs can help make decisions, but business systems remain the source of truth.

[View DispatchAI on GitHub](https://github.com/MTariq99/dispatchai)
